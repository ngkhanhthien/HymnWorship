Giúp tôi tạo một plan để upload dữ liệu các bài nhạc, file nhạc và file ảnh khuôn nhạc lên firebase. Mục tiêu là chia thành các bước, có thể kiểm tra kết quả từng bước. Mỗi bước thêm code vào phải không quá 250 dòng code, và đảm bảo tuân thủ DRY. File plan để ở thư mục gốc HymnWorship, có check list để xem từng phần nào đã chạy và được cập nhật tự động. Bạn là một kiến trúc sư dữ liệu trên firebase, và cần giúp tôi để đẩy dữ liệu lên đó, nhưng để sau này có thể dễ dàng lấy về cho trang web của tôi.
